# 基金评分系统

一个**单文件 HTML** 的基金 / 股票分析工具。双击就能用，不用安装、不用注册、不用后端，数据全部留存在你自己的浏览器里。

> 当前版本 **v2.32** · 更新日期 2026-11-11

---

## 为什么做这个

市面上的基金工具，要么在别人的服务器上跑（你的持仓数据要交给它），要么只给你一个分数、不告诉你分数怎么来的。

这个工具反过来：

- **算法全公开**，权重可以自己拖，每一分怎么算出来的都能看见
- **数据不出本机**，持仓存在浏览器 localStorage，不上传任何服务器
- **单文件、零依赖**，不加载任何 CDN、不用 npm、不用框架，断网也能打开界面（只是拉不到行情）

## 功能

八个页签，覆盖从「选基」到「管持仓」到「看股票」的完整链路。

### 💼 我的持仓

- **导入**：直接选 Excel（.xlsx），或者把支付宝 / 天天基金的持仓页**复制粘贴**进来，自动识别
- **多平台合并**：天天基金 + 支付宝直持 + 支付宝帮你投（投顾），分开记录、合并统计
- **防错码校验**：自动核对表内名称与官方基金名称，抄错代码会挂红色警示条，并按名称反查出正确代码，一键修正
- **止盈线提醒**：浮盈大的持仓自动算「距历史最高点的回撤」，过 15% 提示减 1/3，过 25% 重点提醒
- **一键生成体检报告**：导出单文件 HTML（组合总览 + 板块结构 + 止盈状态 + 逐只体检明细）

### 基金评分

- 五维加权：**收益能力 / 抗跌能力 / 稳定性 / 夏普比率 / 规模与年限**
- 权重可拖，内置三种预设（均衡 / 追收益 / 求稳）
- 详情页三大件：**业绩走势图**（叠加沪深300 对比线）、**阶段业绩与同类排名**、**前十大持仓**

### 按主题选基

按行业 / 概念主题筛基金，支持质量筛选与一键优选。

### 🚀 潜伏雷达

找「大涨前」特征的基金：不看已经涨了多少，看有没有启动迹象。

### 按基金经理选基

按经理的任职年限、历史业绩、管理规模筛人。

### 基金PK对比

两只基金同图对比，历史记录本地保存。

### 📈 股票诊断

输入 6 位 A 股代码，给出未来一周的**技术面倾向**：

- **七因子加权**：趋势 24% / 动量 14% / MACD 16% / KDJ 10% / RSI 10% / 量能 10% / 资金流 16%
- 综合分 **-100 ~ +100**，五档倾向（偏多 / 略偏多 / 震荡 / 略偏空 / 偏空）
- 参考**支撑位 / 压力位**（近20日高低 + 布林轨 + 60日高低）
- **分档操作建议**，带触发条件（持有 / 低吸 / 观望 / 减仓 / 规避）
- 60 根蜡烛图，**鼠标悬停显示当日明细**（开高低收、涨跌幅、成交量、成交额、振幅、换手率、MA5/10/20），顶部 MA 价格栏随悬停联动
- 量比分档标签（异动放量 / 明显放量 / 温和放量 / 缩量 / 极度缩量）
- 自动列出风险信号（RSI 超买、放量大跌、主力连续流出、跌破 20 日线等）

### 🎯 选股排行

按当日**成交额**取全市场最活跃的 N 只股票（300 / 800 / 1500 可选），逐只跑同一套七因子模型，按**综合分降序**排行。

- 适合每天 **14:30 尾盘前**扫一遍
- 表格含：综合分（带红绿条）、档位、量比、换手、**距20日高位置**、MA5/MA20、成交额
- **关键因子归因**：一句话说明它为什么排在这儿（如「强：趋势/量能 · 弱：KDJ」）
- 可筛选（偏多 / 强势 / 放量异动 / 排除 ST）、按板块过滤、导出 CSV
- 点股票名直接跳到「股票诊断」看 K 线和支撑压力位

## 数据从哪来

全部来自**公开接口**，不需要任何账号或 API Key：

| 用途 | 接口 |
|---|---|
| 基金净值、持仓、经理、规模 | 天天基金 `pingzhongdata/{code}.js` |
| 基金搜索 | 天天基金 `fundsuggest` |
| 基金阶段业绩与同类排名 | 东方财富 F10 |
| A 股实时快照 / 日K / 资金流 | 东方财富 `push2` / `push2his` |
| 全市场行情列表 | 东方财富 `push2` clist |

**你的数据只有一类会上网**：查询代码本身（比如你查 600519，就会向东方财富请求 600519 的行情）。你的持仓、成本、盈亏**从不外发**。

## 已知限制（请务必读）

这个工具是**纯前端**的，好处是不用服务器，代价是下面这些限制绕不开：

1. **严重依赖第三方接口**。东方财富 / 天天基金一旦改字段、改地址、加风控，对应功能会直接失效，需要改代码才能恢复。这不是偶发情况，是必然会发生的。
2. **可能被限流**。选股排行要拉几百只股票，请求量大时可能被暂时封 IP。页面已做并发限制和重试，但仍可能失败，把样本池调小重试即可。
3. **没有服务保障**。作者是个人，不承诺任何可用性。它就是个自己用的工具，顺手放出来。
4. **移动端体验不完整**。只有部分页面做了窄屏适配，主力场景是桌面浏览器。
5. **持仓数据存在浏览器里**。清理浏览器数据、换浏览器、用无痕模式，数据就没了。重要数据请用「生成体检报告」导出存档。
6. **股票部分的「未来一周倾向」是技术面统计**。不含财报、消息面、大盘系统性风险。回测好看不等于未来有效。
